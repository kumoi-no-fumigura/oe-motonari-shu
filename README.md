## 作品について

戦国大名毛利元就（大江元就）の家集で、題詠の歌を収める。巻末に元亀三年の三条西実澄（実枝）の跋文があり、元就の武と歌の道をたたえる。底本は祐徳稲荷神社所蔵の中川文庫本の写本。

## 底本

- [大江元就集（祐徳稲荷神社所蔵 中川文庫本、写本 1 冊）](https://kokusho.nijl.ac.jp/biblio/100186000/)（祐徳稲荷神社）

祐徳稲荷神社の公開画像です（画像の出典: 祐徳稲荷神社）。

## 本文の作り方

祐徳稲荷神社の公開画像を、国立国会図書館の NDL古典籍OCR-Lite でテキスト化し、原本のページごとに段落に分けました。写本の崩し字の OCR なので、誤りが多く残っています。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 段落で、`段落ID<TAB>本文` の形です。原本の行の切れ目は ⏎ で示しています（⏎ は改行の印で、本文の字ではありません）。50段落ごとにファイルを分けています（1ファイル）。 |
| `uta.tsv` | 作中歌の一覧（番号・段落ID・本文・読み・詠み手・種別・原本のコマ）。 |
| `nijl-oe-motonari-shu.json` | 本文・底本・作品の説明・作中歌のデータをまとめた JSON（訳は入れず、`yaku/` だけに置いています）。 |

段落ID（例: `nijl-oe-motonari-shu-0001`）は、本文を直しても変わりません。

## 誤りを見つけたら


- **Issue で知らせる**：[「本文の誤り」の Issue を作る](https://github.com/kumoi-no-fumigura/oe-motonari-shu/issues/new?template=teisei.yml)。段落ID・いまの本文・直した本文・根拠を書いてください。
- **直接直す**：`honbun/` の該当行を直して Pull Request を送ってください。段落IDと行の順番は変えないでください。

受け取った修正は、底本と照らして確かめてから取り込みます。
